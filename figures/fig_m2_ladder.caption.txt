Figure 2b -- S21 + ring-down coupling-ladder plot (photonics.json:ladder, tcmt_check; out/m2/s21_3d_lad18_s21_N3_...json; out/m2/s21_3d_l18_harminv_N{2,3,4}_...json).

(a) S21(nu) near the cavity line for the res18 N=3 anchor run (band-power and flux routes, independent TCMT fits). The measured dip is only 5.9% deep (fit dip_depth=0.0593), far shallower than a naive lossless single-mode two-port notch (~81%), because the cavity line sits in the guided-band tail (band-tail/Fano dilution). The off-resonance transmission floor beyond +/-5 GHz measures 0.9856. This is a band-tail artifact (cavity line inside the guided-band tail), not a loss -- the brief's >=99.5% off-resonance target is not met, again a band-tail artifact rather than excess loss. Top axis: GHz at the device lattice constant a=586.735 um (photonics.json:geometry.a_um_precise); the raw MEEP nu-axis is scale-invariant.

(b) Ring-down Q convergence: the harminv-fitted Q vs cumulative simulated ring-down periods for N=2/3/4, i.e. the stationarity check underlying each headline Q_loaded (photonics.json requires q_stationary_last2_within_10pct=true for a 'clean' result; all three N pass). This is the ring-down method itself (brief Sec.5 primary Q technique), shown so the reader can see each Q has converged rather than being read off a single noisy window.

(c) Q_loaded(N) at N=2/3/4: N=2: 13783.8, N=3: 7448.1, N=4: 11898.3, against the N-independent in-situ Q_i anchor = 14611.7 (24a-cell capped run). N=2 is flagged as near-critical (Q_loaded within ~6% of Q_i) and excluded from the exponential fit; the refined exclusion criterion also requires a mode-distortion signature |nu0(N) - nu_cavity| (nu_cavity=photonics.json:modes.nu0_a_over_lambda_precise): N=2 pulls the line by 3.21e-04 while N=4 sits within 2.29e-05 of the isolated-cavity value, so N=4's proximity to Q_i is the expected exponential-decoupling trend, not an anomaly. This mirrors the 2D exploratory ladder's own N=2 anomaly (figs/fig_m2_2d_s21_ladder.png) -- a 2D-predicted, 3D-confirmed feature of this geometry.

(d) Q_w(N) = the coupling-only Q backed out via 1/Q_w = 1/Q_loaded - 1/Q_i_anchor: N=2: 243294.4, N=3: 15191.9, N=4: 64072.3, N=5 extrapolated=270227.6. The 2-point exponential fit over the non-anomalous N=3,4 points, ln Q_w = 1.43925*N + 5.31077 (R2=1.0 -- trivial for 2 points, NOT a validated statistical fit), extrapolates to N* = 6.654 (~7 rows) for the A=1% design target Q_w = 200 Q_i = 2.922330e+06. N*=7 sits outside the simulated N in {3,4} and must be read as a design estimate, not a measured result.
